This guide is still being written. Until it is complete, these pages cover the most common networking problems:

* **My robot is not on WiFi.** Follow [Connecting to WiFi](/docs/setup/networking/#connecting-to-wifi). For a university network that needs a login, see [Connecting to an Enterprise WiFi Network](/docs/setup/networking/#connecting-to-an-enterprise-wifi-network).
* **I don't know my robot's IP address.** See [What's my MBot's IP?](/docs/tutorials/get-ip/).
* **There is no WiFi network I can use.** Connect your laptop directly to the robot using [the MBot's Access Point](/docs/setup/networking/#connecting-to-the-mbots-access-point).
* **I can't connect from my laptop.** Your laptop must be on the same network as the MBot. Then follow [Connecting with VSCode](/docs/tutorials/vscode/).
* **Something else.** Check that the networking services are running: see [Networking Services](/docs/troubleshooting/software/#networking-services).
