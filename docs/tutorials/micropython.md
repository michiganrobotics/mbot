## About the MBot
{: .line }

The MBot is an open-source educational robotics platform designed for learning robotics programming and autonomous navigation. It features:

* Raspberry Pi-based control system
* Lidar sensor for mapping and navigation
* Omnidirectional drive system
* Support for multiple programming languages including Python, C++, and MicroPython

For more information about the MBot platform, check out our other [tutorials](/docs/tutorials/).
